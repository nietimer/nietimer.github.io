矩阵实验室 · matrix()

EDIT
A
transform: matrix(1, 0, 0, 1, 0, 0);

矩阵的 6 个参数直接决定所有 2D 变换：a / d 控制缩放， b / c 控制旋转与倾斜，e / f 控制平移。 任意复杂的 2D 形变最终都会被压缩为这 6 个数。
